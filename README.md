# Melanoma multi-omics analysis

A multi-omics bioinformatics pipeline that studies how melanoma cells respond
and become resistant to combined **BRAF + MEK inhibition (BRAFi + MEKi)**. It
integrates targeted and data-independent phosphoproteomics, transcriptomics,
clinical genomics and machine learning across the full time course of the
resistance process.

## Two ways to read the project

The work is organized around three **biological phases** of BRAFi + MEKi
treatment (the signaling-transition-kinetics model in `docs/phase2/`), which the
21 executable **pipeline stages** map onto:

| Phase | Timeframe | What happens |
|-------|-----------|--------------|
| **Phase 1** — Acute suppression | 6 h – 24 h | MAPK shutdown; KSEA & ERK1/2 drop |
| **Phase 2** — Adaptive rewiring | 48 h – 72 h | PI3K/AKT/mTOR & RTK rebound; feedback loss |
| **Phase 3** — Consolidated resistance | 3 d – 90 d | Stable multi-omics signatures; invasive switch |

Full, per-stage documentation (with datasets, figures, tables and key results)
lives in **[`docs/phases/`](docs/phases/README.md)** — start there.

## Quick start

```bash
pip install -r req.txt
python3 run.py                   # run every stage in order (1–21) + regenerate docs
python3 run.py 15 16 17          # run only selected stages
python3 generate_phase_docs.py   # regenerate docs/phases/ from the catalog
```

Each stage writes figures to `results/figures/`, tables to `results/outputs/`
and a console log to `results/logs/`. `run.py` runs each stage as an isolated
subprocess, so one failure does not stop the others, and prints a summary.

## Datasets

| Accession | Type | Content |
|-----------|------|---------|
| PXD013923 | Phosphoproteome (SILAC) | Acute BRAFi/MEKi/ERKi in A375, 30 min |
| PXD022992 | Phosphoproteome (directDIA) | 6 melanoma cell lines, basal |
| GSE110054 | Transcriptome (RNA-seq) | BRAFi time course, M229/M397 (3 d–90 d) |
| TCGA-SKCM | Genomics + clinical | 470 cutaneous-melanoma patients |
| OmniPath | Kinase-substrate network | 39,037 relations, for KSEA |
| PXD026557 / GSE199405 | Phospho + protein + microarray | AR-overexpression (resistant) vs control |

Dataset provenance is documented in `datas/README_public_datasets.md`.
